# 轻压PDF - PDF&图片在线压缩工具
## 项目介绍
一款轻量化网页压缩工具，支持PDF、JPG、PNG文件压缩，可自定义压缩画质，PNG自动保留透明通道。
- PDF：图片重采样压缩，大幅减小扫描版PDF体积
- 图片：无损/均衡/极致多档位压缩

## 在线使用地址
https://pdf-compress-tool-jscbjx749suj3jkudflayj.streamlit.app/

## 本地运行方法
### 方式1：一键启动
Windows系统直接双击【启动工具.bat】，自动安装依赖并打开本地网页。

### 方式2：手动命令启动
```bash
pip install -r requirements.txt
